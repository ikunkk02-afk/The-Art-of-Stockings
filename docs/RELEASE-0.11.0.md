# 丝袜艺术 0.11.0 · 盔甲架闻袜与穿戴记录

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。替换旧版 JAR，客户端和服务器一起更新。

## 盔甲架闻袜

先让任意玩家完整穿过丝袜一次，再脱下并手持右键放到盔甲架腿部展示位。自己或别人穿过的都可以，不要求有脚臭。

在 2.25 格内下蹲，看向盔甲架丝袜的脚部，持续 1.5 秒即可获得 30 秒“兴奋”（移动速度 +10%），沿用 5 秒触发冷却。全新丝袜只放上盔甲架展示不算穿过，不能触发。

支持小型盔甲架。隔墙、站起、移开视线、取走丝袜或更换目标会中断；隐藏标记用的 Marker 盔甲架不参与。原来的玩家之间闻袜继续可用。

## 穿戴记录

物品会保存“曾被玩家穿过”记录，并在提示中显示。独立穿戴位置、Curios / Accessories 功能栏、双手和头部的实际穿戴都会记录。只拿着、取消未完成的穿上动作或仅放在外观槽展示不算。

记录随物品保存和同步，转交给另一玩家、放上盔甲架、重进存档、染色、款式改造和死亡掉落后保留。原有颜色、深度、自定义图案和名称继续保留。

更新前已穿在身上的丝袜会自动补记，旧臭袜也可直接识别。旧版已经脱下且没有脚臭标记的丝袜没有可追溯数据，需要再穿一次。

保留无饰品模组魅惑、头套从头顶向下穿、手部和头部款式图案、满不透明度、脚臭与洗脚水等全部功能。完整说明见《完整使用与合成说明.md》。

自动验证包括实际穿上→脱下→放置→本人和另一玩家闻袜获得效果、恰好 600 刻时长、冷却、存档/网络/转移、空架和新袜拒绝、遮挡、小型架与中断条件。
