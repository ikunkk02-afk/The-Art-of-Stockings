# 丝袜艺术 0.10.0 · 深色、立体肉垫与全身穿戴

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。移除旧版 JAR 后替换，联机两端使用同版。

## 深色与猫肉垫

- 猫肉垫丝袜默认灰紫底色、深玫瑰图案色，面料更厚实，物品图标减少泛白。既有染色继续保留。
- 脚底主肉垫和四枚趾垫轻微凸起，跟随脚部和穿脱动作。
- 全部款式的调色板新增“颜色深度”0–100%。0% 保留当前款式默认面料；提高深度会加深颜色、增强遮盖度、减弱高光。RGB 与不透明度仍然单独设置，渔网孔和绘画的全透明区域继续透明。
- 深度随物品保存和同步，也会在合成、穿脱、死亡掉落时保留。“还原”恢复打开调色板前的设置。

## 全身、手部和头部

**全身丝袜合成：过膝丝袜 + 皮革，无序合成。** 支持原有染色，改造保留名称、脚臭、不透明度和深度。

普通手持右键仍穿到双腿。潜行手持右键打开选择菜单，可选双腿、双手、头部；全身丝袜选择“全身”。双手共用一双丝袜，覆盖手掌和前臂；全身款覆盖躯干、四肢和头部。

主手空手潜行右键脱下；有手部或头部丝袜时先选择部位。穿脱仍为 3.6 秒，切换源物品取消，不会吞物品。三个位置均不占原版盔甲栏，遵循存档、多人同步和 keepInventory。手部支持第一人称及纤细皮肤；头部为外观层，不改变第一人称视野。

Curios / Accessories 继续管理腿部及全身款；手部和头部使用模组自身独立位置。原有魅惑只由功能饰品丝袜栏提供。为手部、头部单独调色，可将其脱下放到副手再用调色板。

## 闻袜与兴奋

在 2.25 格内，面对另一玩家脚部下蹲持续 1.5 秒，对方实际穿着腿部丝袜或全身款时，获得 30 秒“兴奋”：移动速度 +10%。5 秒内不会重复触发。无需脚臭，可用牛奶清除。

更换目标、看向别处或站起会中断进度。隔墙、太远、自闻、死亡/旁观玩家、仅手部或头部穿戴均不会触发。

## 验证与美术

自动测试覆盖新合成、颜色深度的保存和上传边界、三个位置的事务与掉落、真实 ServerPlayer 更新中的闻袜判定、冷却和换目标重置，以及实际渲染网格。图形界面、第一人称最终观感、整合包和光影仍需实机查看。

全身丝袜物品图标和兴奋图标通过内置 image_gen 生成，原图、提示词与游戏尺寸预览附源码包 `art/generated/0.10.0/`。本次不含第三方模组；可选依赖版本沿用 0.9.0。
