# 丝袜艺术 0.10.2 · 手部/头套图案与动画修正

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。替换旧版 JAR，联机两端同版。

修正 0.10.0–0.10.1 中手部和头部只铺通用底色、丢失款式图案的问题：

- 使用每款丝袜原有的分段 UV 和袜口纹理，保留自定义图案和渔网孔。
- 条纹款保留清晰双色横条纹，狐狸款在指尖和头顶保留深色端部。
- 渐变款从袜口色过渡到末端色，穿戴部位变化不会丢失两色。
- 猫肉垫在双手的掌面和头套正面显示，继续使用图案色；动画中只显示已经套上的部分。
- 第一人称双手与第三人称使用同一套图案映射。

修正头套从脖子往上生成的问题：穿上时先把双手抬到头顶，头套的闭合端落在头顶，再把开口向下拉到颈部。脱下时把开口向上提，布料最后离开头顶。保留原有 72 刻穿脱事务、取消、存档和掉落规则。

保留 0.10.1 的不透明度增强：100% 时面料完全遮盖皮肤，网孔和自定义图案的全透明区域仍然透明。

测试包中的《图案与头套方向预览.png》来自实际输出网格和原纹理的离线正面渲染，方便核对图案及覆盖方向，不是游戏截图。游戏光照、第一人称最终画面和光影仍需实机验收。完整玩法见《完整使用与合成说明.md》。
