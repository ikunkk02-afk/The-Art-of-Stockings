# 丝袜艺术 0.8.0 · 游戏内绘画

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。移除旧版丝袜艺术 JAR，放入 `theartofstockings-0.8.0.jar`。客户端与服务端都需更新到同一版本，旧存档和物品会继续保留。

## 直接在游戏里画丝袜

1. 过膝丝袜 + 纸，合成自定义丝袜。
2. 手持丝袜调色板，将自定义丝袜放在副手，或先穿在身上。
3. 右键打开调色板，点击“游戏内绘画”。
4. 选择正面、背面、两侧、脚底、袜口或整张纹理，左键绘画、右键取色。可使用画笔、橡皮和填色，调整笔刷大小、颜色和画笔不透明度。
5. 右侧预览会实时显示图案。撤销/重做以笔画为单位；清空和还原也可以撤销。
6. 点“完成绘画”返回调色板，再点“应用”保存到丝袜。服务器确认后关闭编辑界面。“取消”不会保存本次画布。

“导出 PNG”会把当前草稿另存到游戏的 `config/theartofstockings/` 文件夹，不覆盖已有图案。左右腿共用图案。原有 RGB 染色、不透明度、脚臭、穿脱动作和饰品兼容继续可用。

## 导入绘图软件编辑的 PNG

旧版将图片限制在 10 KiB，常见绘图软件保存的图案可能超过限制，错误原因也没有清楚显示。0.8.0 移除了此限制：现在接受最大 **4096×4096、16 MiB 的方形 PNG**，会自动缩放到 256×256 并转换为 8 位 RGBA，移除不必要的编辑软件信息。

点击“导入 PNG”或把文件拖进调色板。导入后底色自动设为白色，保留原图颜色；可以继续调色。不支持的格式、非方形图片、文件损坏或无法读取时会显示具体聊天提示。模板和 UV 指南在测试包的 `自定义纹理/` 文件夹。

完整图案以小块上传并一次提交；存档改用 NBT 字节数组，解决大图超过 NBT 字符串长度的问题，并兼容旧版字符串纹理。物品更换、穿脱期间或编辑会话失效时会拒绝旧请求，避免把旧草稿覆盖到另一双丝袜。

## 哑光款重做

哑光款改为更密实的低对比织纹，继续取消额外高光层，并加入 LabPBR 最大粗糙度、低反射率的材质贴图。支持 LabPBR 的光影可读取这些材质数据；具体整合包和光影下的最终观感交给用户验收。不透明度仍可自由调整。

## 款式配方与依赖

在原有过膝丝袜上加一种材料，无序合成：

| 材料 | 结果 |
| --- | --- |
| 紫水晶碎片 | 渐变丝袜 |
| 线 | 连裤袜 |
| 剪刀 | 渔网丝袜，剪刀返还 |
| 荧光墨囊 | 发光丝袜 |
| 白色羊毛 | 条纹丝袜 |
| 兔子皮 | 猫肉垫丝袜 |
| 墨囊 | 哑光丝袜 |
| 甜浆果 | 狐狸丝袜，上橙下棕黑 |
| 纸 | 自定义丝袜 |

调色板：纸 + 木棍 + 红色染料 + 绿色染料 + 蓝色染料。

本模组可以单独运行。饰品栏可选择 Curios 9.5.1+1.21.1，或 Accessories 1.1.0-beta.54+1.21.1。Accessories 的 owo-lib 前置需要 **0.12.15.6-beta.1+1.21** 或更新的兼容版本。本包不包含第三方模组。两者同时安装时，丝袜优先使用 Accessories。

本版通过服务端 GameTest、实际网格写入、PNG 转换、画布工具、NBT 与网络回归检查。图形界面操作与整合包视觉由用户测试；本次没有再次自动启动图形客户端。
