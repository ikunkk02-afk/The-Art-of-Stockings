# 丝袜艺术 0.7.1 修复版

修复猫肉垫丝袜在调色板预览及世界渲染中的 `Not building!` 崩溃：袜身、高光和肉垫改为完整、独立的渲染批次。新增无窗口的实际网格回归检查，确认旧版可复现而修复版通过。

请移除 0.7.0 JAR，替换为本包的 0.7.1，客户端和服务器一并更新。无需修改存档或物品。

适用：Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。客户端和服务器均安装相同版本。

## 安装

将 `theartofstockings-0.7.1.jar` 放入 `mods`，移除丝袜艺术的旧版 JAR，再启动游戏。

本模组可单独运行。需要饰品栏时可安装以下任一种：

- Curios 9.5.1+1.21.1（NeoForge）。
- Accessories 1.1.0-beta.54+1.21.1（NeoForge），以及它的前置 owo-lib **0.12.15.6-beta.1+1.21** 或更新的兼容版本。请更新旧版 owo-lib，否则当前 NeoForge 的网络握手可能断开。本版会在加载阶段提示前置版本不合要求。

两者同时安装时，本模组优先使用 Accessories 的丝袜栏。其他模组在这两套饰品系统之间的兼容需求由它们自身决定。

## 新增款式

以下均为无序改造配方，以原有“过膝丝袜”为原料。

| 款式 | 额外材料 | 外观 |
| --- | --- | --- |
| 条纹丝袜 | 白色羊毛 | 双颜色横条纹 |
| 猫肉垫丝袜 | 兔子皮 | 脚底猫肉垫，可独立染色 |
| 哑光丝袜 | 墨囊 | 无额外高光层 |
| 狐狸丝袜 | 甜浆果 | 上段橙色、下段棕黑色，清晰分界 |
| 自定义丝袜 | 纸 | 可导入自己的 PNG |

调色板支持全部款式的 **0–100% 材质不透明度**。条纹、肉垫、狐狸款可分别选底色与图案色；使用一份染料改图案色，两份染料按合成格顺序设置两色。

自定义丝袜的调色板支持“导入 PNG”、拖入 PNG、“清除纹理”和“导出绘制模板”。PNG 必须为 64×64、128×128 或 256×256，最大 10 KiB。图片随物品保存并联机同步。保持白色底色可以保留原图颜色；透明度滑杆会乘以 PNG 自身 Alpha。模板说明见 `自定义纹理/README.md`。

## 穿戴与测试

右键手持丝袜可按原有动画穿上；主手空手、潜行右键可按动画脱下。有饰品模组时，动画完成后操作实际丝袜栏；也可通过饰品界面直接穿脱。护腿可以同时装备。

建议检查新款图案、PNG 导入与保存、透明度、护腿共存、饰品栏操作，以及原有脚臭和洗脚水玩法。自动测试已覆盖存储、合成、网络编码、穿脱事务和死亡处理；实机视觉与整合包效果由用户验收。

本包不包含第三方饰品模组及其前置。完整变更和开发验证记录位于项目 README 与 `docs/TESTING.md`。
