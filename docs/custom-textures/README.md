# 自定义丝袜 PNG

使用 [custom_stockings_template.png](custom_stockings_template.png) 绘制，参照 [uv_guide.png](uv_guide.png)。二者都是 256×256；也可以将模板按比例缩到 128×128 或 64×64。

同一图案镜像复用于左右腿。贴图左上角为 (0,0)，以下坐标按 256×256 模板计：

| 区域 | X | Y |
| --- | --- | --- |
| 袜口与细边 | 0–191 | 0–19 |
| 正面 | 0–47 | 32–199 |
| 右侧 | 48–95 | 32–199 |
| 背面 | 96–143 | 32–199 |
| 左侧 | 144–191 | 32–199 |
| 脚底 | 0–47 | 208–255 |

袜身从上到下对应从大腿到脚尖；脚底的 UV 方向反转。各相邻面的左右边缘建议使用连续图案，避免接缝。保持 PNG 的 Alpha 通道可绘制镂空或透肤面料。

1. 合成自定义丝袜：过膝丝袜 + 纸。
2. 手持丝袜调色板，把自定义丝袜放在副手或穿在身上。
3. 点击“导入 PNG”，或将文件直接拖到调色板界面。接受最大 4096×4096、16 MiB 的方形 PNG，自动转为 256×256 RGBA。无需自己压缩到 10 KiB。非方形、文件损坏等情况会在聊天中显示具体原因。
4. 底色选白色可以保留原图颜色。不透明度 0–75% 对原图 Alpha 统一缩放；75–100% 会额外增强面料遮盖，100% 使非透明像素完全遮盖。全透明区域仍透明，原始 PNG 不会被改写。需要保留原图的半透明笔触时，可调低丝袜不透明度。
5. 点击“应用”。图片随物品保存并同步；“取消”放弃本次编辑。

“导出绘制模板”会在游戏的 `config/theartofstockings/` 目录创建模板并打开文件夹；已存在的模板不会覆盖。模板和 UV 图均为本项目原创资产。

## 直接在游戏中画

在自定义丝袜的调色板点“游戏内绘画”。选择“正面”“背面”“左侧”“右侧”“脚底”“袜口”或“整张纹理”，用左键绘画、右键取色；橡皮会擦为透明，填色只作用于当前视图中的连通区域。笔刷大小、画笔不透明度和 HEX 颜色可以精调。

“撤销/重做”以一次笔画为单位；“清空此面”和“还原画布”也能撤销。左右腿共用同一纹理，右侧模型会实时展示画布修改。“完成绘画”只把草稿返回调色板，继续点“应用”才保存到实际物品；点击画板“取消”会丢弃本次画布。“导出 PNG”可将当前草稿另存到配置文件夹，避免覆盖原图。

联机保存使用小块上传，完整图片校验后一次写入；改动目标丝袜时旧草稿不能覆盖新物品。新版图片以 NBT 字节数组保存，兼容旧版字符串纹理，重进游戏后仍保留。
