# 丝袜艺术 0.9.0 · 魅惑与新界面图标

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。替换旧版丝袜艺术 JAR，客户端与服务器一起更新。旧存档、款式、染色和自定义绘画继续保留。

## 配色

- 条纹袜默认改为更深的灰紫与近黑，面料遮盖度提高、高光减弱。
- 狐狸袜改为深焦橙与深棕黑，继续保持上橙、下棕黑的清晰分界。
- 物品栏图标也减少了泛白。已有染色不会被覆盖，面料本身会显示得更饱满；仍可用调色板调整颜色和透明度。

## 魅惑与折扣

丝袜放进 Curios / Accessories 的**功能丝袜栏**时，自动获得“魅惑”。取下后立即失去。外观槽、独立穿戴层和护腿栏不提供 Buff。

16 格内的村民和友好生物尝试靠近，约 3 格停下。保护其他玩家的宠物、坐下指令和正常遇险/睡觉/交易行为。水生动物只在玩家位于水中时跟随；敌对怪物不受吸引。带脚臭时，村民仍执行原有避让。

带魅惑打开村民交易，第一项支付物品按基础数量优惠 20%，至少优惠 1 个，最低仍支付 1 个。与原版声望、村庄英雄一起计算；关闭交易后临时折扣复位，反复打开不会累积永久折扣。

## 生图美术

本次通过内置生图工具生成并接入：丝袜饰品槽位占位图、魅惑图标、脚臭图标、穿脱进度条和模组图标。槽位图补上纹理图集注册；模组列表会显示新的模组图标。

测试包附 `模组图标.png`、`界面图标预览.png`；完整原图与生成提示词保留在源码包 `art/generated/0.9.0/`。运行时采用 16×16 槽位图、18×18 状态图标、112×14 进度条和 512×512 模组图标。

## 原有功能与依赖

十种丝袜、游戏内画板、PNG 导入、透明度、穿脱动画、护腿共存、脚臭和洗脚水玩法继续可用。自定义款：过膝丝袜 + 纸，再用调色板点“游戏内绘画”；完成绘画后点“应用”保存。

可选 Curios 9.5.1+1.21.1，或 Accessories 1.1.0-beta.54+1.21.1；Accessories 的 owo-lib 前置需 0.12.15.6-beta.1+1.21 或更新兼容版本。本包不包含第三方模组，两者同时安装时优先使用 Accessories。

自动验证覆盖实际交易优惠与复位、原版优惠叠加、Buff 功能栏限制、宠物/敌对边界、村民和动物实际移动，以及原有大图存档、绘画和渲染回归。实机 UI、具体光影和整合包效果交给用户验收；本次没有自动操作客户端。
