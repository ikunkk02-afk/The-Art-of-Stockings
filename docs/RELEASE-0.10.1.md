# 丝袜艺术 0.10.1 · 不透明度增强

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。替换旧版模组 JAR，联机两端一起更新。

修正玩家反馈的“不透明度拉满仍然太浅”：原先的 100% 只是完整显示带透肤 Alpha 的原材质。现在滑杆最后一段会消除面料自身的透肤，100% 时所有实际面料像素完全遮盖皮肤，并将额外高光降低 90%，减少泛白。

- 0–75% 沿用原有透肤计算，仍能做轻薄效果；75–100% 逐渐增强，拉满更厚实。
- 渔网孔、丝袜外部空白、自定义图案中完全擦掉的区域仍然透明，不会糊成整块。
- “颜色深度”继续独立生效，想在完全遮盖后继续变深，可提高深度或调整底色。
- 旧物品的不透明度数值继续保留，原来已是 100% 的物品更新后直接变厚实，不需要重新合成。
- 腿部、全身、双手、头部、第一人称手部和调色板/画板模型预览使用同一套遮盖计算；画板修改会刷新实时预览。PNG 原文件和绘画 Alpha 数据不被改写。

本次保留 0.10.0 的全部功能。全身丝袜：过膝丝袜 + 皮革。潜行手持右键选择双腿、双手或头部；主手空手潜行右键脱下。闻袜、兴奋、魅惑、脚臭、洗脚水和 Curios / Accessories 兼容继续可用。完整玩法见测试包内《完整使用与合成说明.md》。

自动验证直接读取全部 11 种实际面料 PNG，运行生产用像素转换，检查满不透明度的遮盖、透明网孔、颜色保持、滑杆连续增强和高光衰减；另保留原有网格和游戏测试。最终界面、第一人称和光影观感仍需实机查看。
