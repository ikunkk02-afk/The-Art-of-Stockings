# 丝袜艺术 0.10.3 · 无饰品依赖的魅惑

Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。替换旧版 JAR，联机两端一起更新。

修正魅惑只检查 Curios / Accessories 栏位、遗漏模组自身穿戴位置的问题。现在未安装任何饰品模组时，直接穿着腿部丝袜或全身丝袜也会获得魅惑，村民/友好生物吸引和 20% 村民交易优惠继续生效。

穿上动作完成后获得效果，脱下完成后移除。已有存档中穿着的丝袜更新后自动生效，无需重新合成。只拿在手里、放进背包或 Accessories 外观槽不会触发；安装饰品模组时仍读取实际功能栏，显示开关不影响加成。

手部和头部图案、头套自上而下的动画、满不透明度、闻袜兴奋、脚臭和洗脚水等原有功能继续保留。完整说明见《完整使用与合成说明.md》。

自动测试覆盖独立穿戴、原生饰品栏、全身丝袜、完整穿脱中的效果时机、实际交易折扣及复位，并在无饰品模组环境验证村民和动物实际靠近。四种依赖配置均运行同一套测试。
