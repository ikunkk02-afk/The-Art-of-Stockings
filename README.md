# The Art of Stockings · 丝袜艺术

**0.11.0** · Minecraft Java **1.21.1** · NeoForge **21.1.265+** · Java **21** · MIT

0.11.0 为丝袜保存玩家穿戴记录；自己或别人穿过的丝袜放到盔甲架上后，也能下蹲闻袜获得 30 秒兴奋。保留无饰品依赖的魅惑、手部/头套图案与动画、满不透明度增强和原有全部玩法。

## 十一种丝袜与合成

| 款式 | 合成方法 |
| --- | --- |
| 过膝丝袜 | 工作台左右两列各放三根线 |
| 渐变丝袜 | 过膝丝袜 + 紫水晶碎片；可同时加入一至两种染料 |
| 连裤袜 | 过膝丝袜 + 一根线；可同时加入染料 |
| 渔网丝袜 | 过膝丝袜 + 剪刀；可同时加入染料，剪刀完整返还 |
| 发光丝袜 | 过膝丝袜 + 荧光墨囊；可同时加入染料 |
| 条纹丝袜 | 过膝丝袜 + 白色羊毛；两种颜色交替的横条纹 |
| 猫肉垫丝袜 | 过膝丝袜 + 兔子皮；脚底有独立染色的猫肉垫 |
| 哑光丝袜 | 过膝丝袜 + 墨囊；厚实织物、无额外高光层、最大粗糙度材质 |
| 狐狸丝袜 | 过膝丝袜 + 甜浆果；默认上橙、下棕黑，清晰分界 |
| 自定义丝袜 | 过膝丝袜 + 纸；调色板可导入自己的 PNG |
| 全身丝袜 | 过膝丝袜 + 皮革；覆盖双腿、躯干、双臂和头部 |
| 丝袜调色板 | 纸 + 木棍 + 红色染料 + 绿色染料 + 蓝色染料 |

以上改造与调色板均为无序合成。改造保留原有染色和自定义名称。

普通、连裤袜、渔网与发光款都可以再次与一个或多个染料混色。渐变款加入两种染料时，合成格子从左到右、从上到下的第一种设袜口，第二种设脚尖；只有一种染料时只改脚尖。普通丝袜直接加入两种染料仍是原有混色，加入紫水晶才改造为渐变款。

条纹、猫肉垫和狐狸款也支持一至两种染料：两种依次设置底色、图案色；一种只改图案色。狐狸款的底色对应上段，图案色对应脚尖至脚踝的下段。哑光、自定义款使用普通混色。全部改造保留名称、脚臭和不透明度。

## 调色板

手持调色板右键。优先编辑副手丝袜，其次是已穿的丝袜，最后是背包中第一双。

- 原版背包灰色面板、自带按钮、RGB 滑杆和输入框；文字与预览不经过重复背景处理。
- 三条原版 RGB 滑杆和六位十六进制色值支持精确选色；16 个染料色卡支持快捷选色。
- 渐变款的袜口与脚尖独立选色；条纹、猫肉垫和狐狸款的底色与图案色独立选色。交换按钮可互换两色。
- 全部款式都有 0–100% 材质不透明度滑杆；0% 完全隐藏，0–75% 沿用原有透肤计算，75–100% 逐渐提高面料像素本身的遮盖度。100% 时面料完全不透肤并减弱高光泛白；网孔和自定义图案的全透明区域保持透明。旧物品已设为 100% 时更新后直接生效。
- 0–100%“颜色深度”继续单独控制颜色加深；0% 不额外加深颜色，越高颜色越深、面料越密实、高光越弱。RGB 与不透明度仍可分别设置。想保留透肤可调低不透明度，想在完全遮盖后继续加深可提高颜色深度。
- 右侧显示实际模型与材质在盔甲架上的 3D 局部预览；预览使用统一照明，发光款的暗处效果需在世界中查看。
- “还原”恢复本次打开前的颜色、深度、不透明度与自定义图案；“取消”不保存；“应用”才保存。
- RGB 选色不额外消耗染料。换物品、开始穿脱或不再手持调色板时，旧请求不会覆盖物品。

自定义款显示“导入 PNG”“清除纹理”“游戏内绘画”和“导出模板”。支持文件选择和拖入 PNG。导入支持 **最大 4096×4096 的方形 PNG，文件不超过 16 MiB**；自动转换为 256×256、8 位 RGBA，移除绘图软件附加信息。旧版 10 KiB 限制已移除，保存失败会显示具体原因。导入后底色自动设为白色以显示原图颜色，仍可继续染色。模板保存在 `config/theartofstockings/custom_stockings_template.png`，不会覆盖已编辑文件；另附 [模板与 UV 说明](docs/custom-textures/README.md)。

游戏内绘画板支持正面、背面、左右侧、脚底、袜口与整张纹理视图。提供画笔、橡皮、连通填色、右键取色、HEX 色值、16 色色卡、1–16 像素笔刷与画笔不透明度。支持撤销/重做、清空单面、还原画布及导出 PNG，右侧实时预览实际模型。点“完成绘画”返回调色板，再点“应用”保存到物品；“取消”不保存本次画布。绘画数据会分块上传，服务器确认保存后才关闭调色板。

PNG 数据直接随物品保存、传给服务器和其他玩家，其他人无需单独安装资源包。清除纹理恢复默认面料；颜色与不透明度仍可单独修改。

哑光款使用更密实的低对比织纹，取消高光层，并提供 LabPBR 粗糙度/反射率贴图。支持该材质标准的光影可以读取全粗糙度、低反射率数据；具体光影中的最终观感仍由用户验收。

## Curios 与 Accessories

两者都是可选依赖；未安装时继续使用本模组的独立丝袜穿戴层。

- 安装 **Curios 9.5.1+1.21.1** 时，所有款式可放入专用“丝袜”栏。
- 安装 **Accessories 1.1.0-beta.54+1.21.1** 时，原生接入专用“丝袜”栏，无需 Curios 兼容层。
- Accessories 的前置 **owo-lib 必须为 0.12.15.6-beta.1+1.21 或更新的兼容版本**。旧版在 NeoForge 21.1.265 的入服握手中会报 `Sided Packet Codec has not been unpacked`；本模组的可选版本约束会提前提示更新。
- 同时安装时优先使用 Accessories，并停止注册本模组的 Curios 丝袜栏。
- 手持右键的 3.6 秒穿脱仍然可用，完成时操作实际饰品栏；也可直接在饰品界面放入、取出。动作进行时锁定丝袜的界面穿脱。
- 旧版独立穿戴层和旧护腿栏里的丝袜自动迁移，保留颜色、名称和其他数据。发生冲突时多出的一双退回背包。
- 护腿可以同时穿着。饰品模组负责自身栏位的保存、同步和死亡处理；本模组不会再掉落第二双。脚臭与调色板也读取实际饰品栏。
- Accessories 的显示开关与外观槽生效；外观槽只改变显示，脚臭与穿脱仍由实际装备槽决定。

## 魅惑

实际穿着腿部丝袜或全身丝袜后获得“魅惑”，无需安装饰品模组；直接穿戴使用本模组的独立位置，安装 Curios 或 Accessories 时读取功能丝袜栏。脱下后移除效果，穿脱动画完成时才改变实际穿着状态。仅放在背包、副手或外观槽不会提供加成；隐藏饰品显示不影响功能。

16 格内的村民和可寻路的友好生物会尝试靠近，在约 3 格处停下，并偶尔冒出爱心。保留遇险、交易、睡觉等行为；坐下的宠物和其他玩家驯养的宠物不会被夺走，水生动物只在玩家位于水中时跟随。敌对生物不受吸引。村民对带脚臭玩家仍优先执行原有避让。

带魅惑打开村民交易时，第一项支付物品按基础数量减免 **20%**，至少优惠 1 个，最低仍支付 1 个。可以和原版村庄英雄/声望优惠共同计算；关闭交易时清除临时价格，重复开关交易不会叠出永久折扣。

新 UI 美术使用内置生图工具生成，包括饰品槽占位图、魅惑/脚臭图标、穿脱条和模组图标。[原图与提示词](art/generated/0.9.0/README.md) 保留在工程中。运行 `tools/integrate_generated_ui.py` 可从原图重新生成游戏尺寸版本。

## 穿戴

手持丝袜右键空气穿上。主手空手，潜行右键空气或方块脱下。穿脱各 3.6 秒（72 刻），动作完成才转移物品，切换手持物品会取消。满背包脱下时物品掉落，创造模式也保留。

丝袜使用独立穿戴层或可用的饰品栏，不占用玩家护腿栏。可以先穿丝袜再穿护腿，也可以穿着护腿穿脱丝袜；右键装备、背包放入和 Shift 装备护腿均按原版规则工作。更换或脱下护腿不会移除丝袜，穿脱丝袜也不改变护腿。丝袜本身仍无护甲值或耐久。

潜行时手持丝袜右键，选择“双腿”“双手”或“头部”。每个部位独立存放一双，双手共用一双。全身丝袜选择“全身”，覆盖双腿、躯干、双臂及头部。普通右键仍默认穿到双腿。双手和头部使用本模组独立穿戴层，可与头盔、胸甲、护腿同时存在，双手支持第一人称及标准/纤细皮肤。手部丝袜覆盖手掌至前臂，不提供护甲值。

手部和头部使用原款式的分段纹理与染色：条纹保持双色分界，狐狸款在指尖/头顶保留深色端部，渐变保持方向，猫肉垫分别显示在手掌与头套正面，自定义图案使用原 UV。头套穿上时先抬手到头顶，再从头顶向下套到颈部；脱下时从颈部向上提，布料最后离开头顶。

主手空手潜行右键时，如果手部或头部也穿着丝袜，会打开部位菜单，选择后开始原有 72 刻穿脱过程。每次只进行一个动作，中断不会转移物品。手部和头部同样支持存档、同步、死亡掉落及 keepInventory。调色板仍优先编辑副手：要单独调色某部位，可脱下放到副手后编辑；无腿部丝袜时也能直接编辑已穿的手部或头部丝袜。

猫肉垫丝袜默认改为灰紫底色和深玫瑰肉垫，原有染色不会被重置；面料稍加深并增厚。脚底的一块主肉垫及四块趾垫具有约 0.24–0.32 模型像素的实际凸起，跟随脚部和穿脱动画移动，图案色仍可单独调整。

## 闻袜与兴奋

靠近另一位穿着腿部丝袜或全身丝袜的玩家，在 **2.25 格内**下蹲并看向对方脚部，持续 **1.5 秒**，获得 **30 秒“兴奋”**，移动速度提升 **10%**。触发后有 **5 秒冷却**。不要求对方已有脚臭。

将曾被玩家穿过的丝袜放到盔甲架腿部展示位后，也能用相同方式闻袜：2.25 格内下蹲，看向丝袜脚部持续 1.5 秒，获得 30 秒兴奋，沿用 5 秒冷却。自己或别人穿过的都可以，不要求有脚臭。全新丝袜只放到盔甲架上展示不会获得穿戴记录，也不能触发此效果。

完整穿上丝袜时记录“曾被玩家穿过”，独立位置、原生饰品功能栏、手部和头部的实际穿戴也会记录。记录随物品保存和同步，脱下、转交、盔甲架存档、染色、款式改造及死亡掉落后继续保留。物品提示会显示这条记录。

站起、看向别处、离开距离、换目标或取下展示的丝袜会中断进度；隔墙和闻自己正穿着的丝袜不触发。仅手部/头部穿戴的其他玩家、死亡和旁观玩家也不作为闻袜目标；自己穿过后放在盔甲架上的丝袜可以闻。服务器校验条件，兴奋可以被牛奶清除。

更新前已穿在身上的丝袜会自动补记；旧版臭丝袜也可直接识别。旧版已经脱下且没有脚臭标记的丝袜无法追溯历史，需要再穿一次。

旧版本存档中已放在护腿栏的丝袜会自动迁移到独立穿戴层，保留款式、颜色与名称。身上丝袜随存档保存并向其他玩家同步。死亡时遵循 `keepInventory`：关闭时掉落，开启时重生后保留。

手持右键盔甲架可放置，空手右键盔甲架腿部取回；保留颜色、渐变两端色与名称。盔甲架继续使用原版护腿展示位。创造模式按原版复制放置规则。

连裤袜袜身延伸至腰部，腰部随身体动作；渔网使用真正透明的菱形网孔。发光丝袜在暗处自发光，不产生方块光照；光晕取决于光影设置。材质叠在皮肤上，不会擦除皮肤本身的裤子和鞋子。

## 脚臭

丝袜、护腿与靴子一起穿满 24,000 游戏刻（正常速度约 20 分钟）会触发脚臭，身体周围浮出黄绿色气味粒子。穿戴时间随存档保存，离线和睡觉跳过的时间不会计入。

开启作弊或拥有 OP 权限的玩家可以输入 `/footodor`，立即给自己施加 60 秒脚臭，无需等待或满足穿戴条件。

8 格内闻到气味的村民会尝试绕开玩家。僵尸、骷髅和苦力怕能在最多 48 格外锁定气味来源，并沿地形追来。脱掉任一层会重置穿戴计时，身上的气味约 1 分钟后散去。牛奶可以清除状态并重新开始计时。

脚臭生效时脱下丝袜，会得到臭烘烘的同一双丝袜，款式、染色和自定义名称都会保留。把臭丝袜放在酿造台上方，下面放普通水瓶，加入烈焰粉即可酿造洗脚水。一双丝袜会被消耗，每批可酿 1 至 3 瓶。

右键喝下洗脚水会获得 10 秒中毒并留下空瓶。潜行右键会掷出瓶子，直接命中时施加 60 秒脚臭，溅到附近的人也会获得较短的脚臭效果。

## 开发与素材

```powershell
.\gradlew.bat build
.\gradlew.bat runGameTestServer
.\gradlew.bat runClient
# 不启动图形窗口的实际渲染网格回归检查（build 也会自动执行）
.\gradlew.bat checkStockingsRendering
# 可选依赖的运行验证
.\gradlew.bat runGameTestServer -PwithCurios
.\gradlew.bat runGameTestServer -PwithAccessories
.\gradlew.bat runGameTestServer -PwithCurios -PwithAccessories
```

`art/gradient_stockings.bbmodel`、`art/pantyhose.bbmodel`、`art/fishnet_stockings.bbmodel`、`art/glow_stockings.bbmodel` 是 Blockbench 工程，含预览配色、模型、UV 和原有两条动画。运行时加载 `src/main/resources/assets/theartofstockings/geo/` 中的 Blockbench 导出几何和共享穿脱动画。游戏使用可染色的中性白材质，工程内示例配色不会限制游戏选色。

`tools/generate_assets.py` 和 `tools/generate_variants.py` 生成原有穿戴材质，`tools/generate_item_textures.py` 生成原有物品栏图标；再运行 `tools/generate_new_styles.py` 生成新款、模板和饰品数据，最后运行 `tools/integrate_generated_ui.py` 恢复生成式 UI 美术。它们需要 Python 与 Pillow。
