# The Art of Stockings 0.11.0

下载 [0.11.0 模组 JAR](theartofstockings-0.11.0.jar)，或 [完整测试包](丝袜艺术-0.11.0-测试包.zip)（含 JAR、安装说明、图案/方向预览和自定义纹理模板）。[完整工程源码包](theartofstockings-0.11.0-project-source.zip) 包含源码、测试、生成工具和美术原图；[SHA-256 校验文件](SHA256SUMS-0.11.0.txt) 用于核对下载文件。

适用 Minecraft Java 1.21.1 / NeoForge 21.1.265+ / Java 21。0.11.0 记录玩家穿戴历史，自己或别人穿过的丝袜放上盔甲架后也可闻袜获得 30 秒兴奋。保留 Curios / Accessories；Accessories 前置 owo-lib 需要 0.12.15.6-beta.1+1.21 或更新的兼容版本。
